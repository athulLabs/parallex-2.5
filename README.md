# PARALLAX 2.5

A mobile-first 2.5D cinematic parallax video studio built with React, TypeScript, Vite and Three.js.

## Current milestone — Phase 1
- Import artwork (PNG, JPG, WebP)
- Manage independent image layers
- Preview layers in a real Three.js viewport
- Adjust layer position, scale, rotation and depth
- Orbit and zoom the camera
- Save a project locally in the browser

## Development
```bash
npm install
npm run dev
```

AI services are not required. The initial editor is designed to work locally in the browser.
